Assessment Setup

These are the standard times. Students with extra time get 10 minutes per 60-minute block of writing (part blocks count as whole), added to their finish time. Students with rest breaks get the same allowance, used from the control HUD.

Control HUD

Opens the supervisor's control screen in a new browser tab. Keep this display running on the projector while you use the HUD: import the student list, start and end rest breaks, and adjust times. Student names are shown only on the HUD, so drag its tab onto the laptop screen (display set to “Extend”) so it never appears on the projector.
